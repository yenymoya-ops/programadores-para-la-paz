El login es el proceso que permite identificar a un usuario antes de acceder a una aplicación. Algunas rutas deben estar protegidas porque contienen información privada o funciones que solo pueden usar usuarios autorizados. Esto ayuda a mantener la seguridad del sistema y proteger los datos. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, tokens, claves de API ni otros datos sensibles de la comunidad.
